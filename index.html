About WeatherNow & Open-Meteo REST API

WeatherNow is a modern, responsive web application engineered for the InternCircle Full Stack Web Development Internship. It demonstrates asynchronous JavaScript architecture, Fetch API handling, Promise lifecycle management, AbortController request deduplication, WMO meteorological code decoding, LocalStorage persistence, and responsive UI design without any third-party UI frameworks.

Open-Meteo Forecast API

Retrieves high-resolution current, 24-hour hourly, and 7-day daily forecast data from international national weather services.

Open-Meteo Geocoding API

Resolves global city queries into geographic latitude and longitude coordinates in real time.

Open-Source & Privacy Focused

No proprietary API key required; zero tracking cookies; complete client-side rendering.
